# 💎 Sun One Jewellery

A full-stack One Gram Jewellery e-commerce website built using the MERN stack.

## 🌐 Live Website

🔗 https://sun-one-jewellery-vercel.vercel.app/

## 📌 Project Description

Sun One Jewellery is a full-stack e-commerce website developed for a jewellery store. The project provides an online platform where users can browse jewellery products and interact with the website through a simple and user-friendly interface.

The project was developed using the MERN stack, consisting of MongoDB, Express.js, React.js, and Node.js.
